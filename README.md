# Personal Portfolio Website

This is a personal portfolio website built using HTML and CSS for Lab 3.

## Features
- **Organized Structure:** HTML files in root, CSS in `css/`, images in `images/`.
- **External CSS:** Styling is completely moved to an external `style.css` file.
- **Float and Clear:** Uses float to position elements and clear to manage the layout.
- **Navigation Menu:** Horizontally aligned using floats.
- **Image Gallery:** Contains 5 project images aligned with floats.

## Pages
- `index.html`: Home page
- `hobbies.html`: Personal hobbies and interests
- `skills.html`: Technical skills and expertise
- `gallery.html`: Project image gallery
- `contact.html`: Contact form

## Deployment
This project is deployed using GitHub Pages.
